# Амино

Сайт архитектурного бюро: 3D-история на первом экране (чертёж → макет → закат → вечер),
горизонтальная галерея проектов, плавная прокрутка и анимации.

## Как устроено
- `index.html`, `styles.css` — разметка и стили.
- `src/main.js` — анимации и прокрутка (GSAP, ScrollTrigger, Lenis).
- `src/scene.js` — 3D-сцена дома на three.js.
- `assets/app.js` — собранный файл, который подключается к странице.
- `assets/img/` — изображения проектов (пока это рендеры 3D-макетов, замените на фото).
- `tools/render.html` — инструмент для рендера картинок из 3D-сцены.

## Сборка после изменений в `src/`
```bash
npm install
npm run build
```
